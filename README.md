### Project title

JLPT Study Tools

### What and why?

Preparing for the Japanese Language Proficiency Test (JLPT) currently requires navigating a fragmented landscape of tools and resources. While each resource specializes in its own realm, It is often hard to navigate, and often overlaps. I want to create a site to aggregate them into one place, with systems such as dictionary, note taking, translating, personal dictionaries, grammar notes, exercise generators, all into one. Additionally, with publicly connected information to keep track of registration dates, countdown, reminders, as to not miss administration deadlines and notices. 

### For whom?

This site will be used for people who is preparing for the JLPT. With the site's generic language resources, it can also be used to help general japanese learners, as a study resource. 

### How?
Users will first register an account. After creating an account, they will go in a short onboarding process to ask their purpose with the website (JLPT or general study), their estimated level of japanese, etc. This information can be used to choose to display JLPT information or not, and what resources should be recommended by default. This can be changed or set to default later in the profile page. 

There will be a dashboard containing the tools available, and a sidebar with recommendations for study and administration information (if JLPT). 

Tools may include: translator, dictionary, grammar lesson cards, vocabulary exercise. (There are APIs for this)
### Scope

Even though this sounds like a lot, a lot of the logic is already present and available through public APIs and tools. This project takes those resources and merges it into one, with some personalization, and a prettier interface. This project is suitable for a semester long project because it mainly focuses on: utilizing public APIs, integrating public tools, setting up database for user personalization, and if time allows, we can integrate AI exercise generation by prompting through AI, or create Duolingo style game exercises for personalized learning.
